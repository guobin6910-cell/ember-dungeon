# 餘燼地城（Ember Dungeon）

一款使用 **Vite + Phaser 3 + JavaScript** 打造的 2D 暗黑奇幻風單機 ARPG 網頁遊戲。
所有像素風美術素材皆以程式即時繪製於 Canvas，音效則透過 Web Audio API 即時合成，不依賴任何外部圖片或音訊檔案。

---

## 快速開始

需求環境：Node.js（建議 v18 以上）

```bash
# 1. 安裝相依套件
npm install

# 2. 啟動開發伺服器
npm run dev
```

啟動後於瀏覽器開啟終端機顯示的網址（預設 `http://localhost:5173`）即可從主選單遊玩。

```bash
# 建置正式版（輸出至 dist/）
npm run build
```

## 操作說明

| 按鍵 / 滑鼠操作 | 功能 |
| :--- | :--- |
| **`WASD` / 方向鍵** | 即時八方向移動並搭配滑鼠游標瞄準施法（遇牆角自動平滑滑動繞障） |
| **滑鼠左鍵點擊地面** | A* 尋路繞障移動至目標位置（按住可持續引導移動） |
| **滑鼠左鍵點擊敵人 / NPC** | 自動追擊攻擊，或移動靠近鐵匠、聖泉、傳送門範圍後**自動觸發互動** |
| **滑鼠左鍵點擊掉落物** | 自動走近並磁吸拾取裝備、套裝、符文、靈球與技能書（金幣靠近自動吸取） |
| **空白鍵 / 滑鼠右鍵** | 閃避翻滾（優先朝 WASD 方向，否則朝游標方向，具無敵幀與冷卻時間） |
| **數字鍵 `1` ~ `5`** | 施放快捷欄對應位置的技能（消耗法力，具冷卻與技能等級加成） |
| **`B` / `I` / `C` 或右下「背包」鈕** | 開啟／關閉「角色・背包・技能書庫」面板 |
| **背包內左鍵點擊物品** | 穿上／卸下裝備，或閱讀技能書習得／升級技能 |
| **背包內右鍵點擊物品** | 直接賣出物品換取金幣 |
| **`F`** | 與身邊最近的 NPC、聖泉或傳送門互動 |
| **`G`** | 在餘燼村開啟深淵傳送門選擇關卡 |
| **`T`** | 在地城中快速傳送返回「餘燼村」進行整備與鍛造 |
| **`M` 或右下「音效」鈕** | 切換靜音／開啟音效 |
| **`ESC`** | 關閉目前開啟的面板（背包、鍛造爐或傳送門） |

### 手機觸控模式（支援多指操作）
系統會自動偵測行動裝置並啟用手機觸控介面（亦可隨時點擊右下角「**觸控:開／關**」按鈕手動切換）：
- **左下虛擬搖桿**：按住拖曳即可 360° 流暢走位，支援邊跑位邊點擊技能或攻擊。
- **右下快捷動作**：
  - **攻擊**：攻擊身邊最近敵人或擊碎木桶／陶罐；長按可連續自動揮砍。
  - **互動**：靠近鐵匠、傳送門、聖泉、寶箱或祭壇時自動高亮顯示名稱（如「鍛造」、「開寶箱」），點擊即刻觸發。
  - **翻滾**：朝搖桿移動方向閃避翻滾，並於按鈕上即時顯示冷卻倒數。
- **技能列智慧自動瞄準**：直接點擊下方 `1~5` 技能圖示，火球、閃現、隕石、寒冰長矛等方向性技能會自動鎖定攻擊目標或最近敵人（若周圍無敵人則朝移動方向施放）。
- **觸控友善背包與預覽**：點擊物品一次可顯示屬性與詞條浮動提示框及下方專屬操作列（「穿上裝備 / 閱讀技能書 / 卸下 / 賣出」），再點一次立即執行；亦可切換背包右上角「**賣出模式**」，免右鍵一鍵賣裝換金幣。
- **螢幕方向建議**：窄螢幕直向遊玩時頂部會顯示可關閉的橫向螢幕建議提示條。

### 難度設定（`difficulty.js`）
可於**主選單**或餘燼村的**深淵傳送門**自由切換 4 種難度，選擇會自動寫入存檔，並於左上 HUD 徽章與結算畫面即時顯示：

| 難度名稱 | 怪物／頭目血量 | 怪物／陷阱傷害 | 經驗與金幣倍率 | 掉寶率加成 | 符文掉落倍率 | 餘燼石獎勵 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **簡單** | 72% | 70% | 90% | +0% | 85% | 標準 |
| **普通** | 100% | 100% | 100% | +0% | 100% | 標準 |
| **困難** | 155% | 140% / 135% | 經驗 +35% · 金幣 +40% | +35% | 135% | 頭目 +1（精英 50% +1） |
| **地獄** | 235% | 195% / 180% | 經驗 +85% · 金幣 +100% | +80% | 180% | 頭目 +2（精英 50% +1） |

## 各系統簡介

### 1. 餘燼村安全區與鐵匠鍛造（`GameScene.js`、`UIScene.js`、`items.js`）
- **鐵匠布朗**：點擊或靠近按 `F` 開啟鍛造爐，支援四大鍛造功能：
  - **強化裝備（`+1` ~ `+10`）**：花費金幣逐步強化武器、盔甲、頭盔或飾品的全部屬性。
  - **重鑄詞綴**：花費金幣重新隨機產生該裝備的數值與附加詞綴（保留強化等級）。
  - **拆解裝備**：將背包中不需要的裝備拆解換取金幣與「餘燼石」。
  - **鍛造新裝備**：依目前已解鎖的最高地城層數打造對應物品等級的新裝備，分為「精工鍛造」（藍／金裝）與消耗餘燼石的「餘燼神鑄」（100% 傳奇金裝）。
- **治癒聖泉**：立即補滿生命與法力；村莊內亦享有高速自然回復。
- **訓練木樁**：供玩家隨時測試普攻傷害與 7 種技能連招手感。
- **深淵傳送門**：可自由選擇從第 1 層到已解鎖最高層的任意無盡樓層出發。

### 2. 無盡多層地城與四大主題地貌（`dungeon.js`、`pathfinding.js`、`textures.js`）
- 每次進入地城皆會隨機生成**起始方位、主線蛇行路徑、分岔支線房、額外迴廊與戰術石柱**，每張地圖皆不相同。
- 四大輪替主題地貌與專屬色調、迷霧與火炬光源：
  1. **焦石地窟**（第 1、5、9… 層）
  2. **血霧墓穴**（第 2、6、10… 層）
  3. **霜骨深淵**（第 3、7、11… 層）
  4. **烈焰王座**（第 4、8、12… 層）
- 擊敗該層 Boss 後立即解鎖下一層並於房內開啟雙傳送門，可無限挑戰更深層的無盡深淵或返回餘燼村強化裝備。

### 3. 8 種地城怪物與 4 大層級 Boss（`Enemy.js`、`Boss.js`）
- **普通與特殊怪物（共 8 種）**：
  - **骷髏兵**：近戰基礎亡靈
  - **骷髏弓手**：遠程拉開距離射箭
  - **血翼蝙蝠**：高速近戰並具吸血能力
  - **死靈法師**：發射暗影法球並定期召喚骷髏援軍
  - **暗影刺客**：潛行透明接近並發動高速突襲斬擊
  - **寒冰巫師**：扇形三發冰箭，命中附帶減速
  - **精英石像鬼**：高血量重擊預警，高機率掉寶與餘燼石
  - **精英熔岩魔像**：高防高攻，死亡時觸發熔岩延遲自爆
- **層級 Boss（隨層數等比強化，50% 以下狂怒）**：
  - **骸骨暴君**：順劈、扇形箭雨與紅道高速衝鋒
  - **血月主教**：血彈新星、追蹤血爆與召喚蝙蝠／法師
  - **霜魂領主**：緩速冰霜彈幕、連續冰柱重擊與順劈
  - **深淵領主**：大範圍順劈、多波紫球新星與追蹤連鎖重擊

### 4. 技能書掉落與 17 大技能系統（`skills.js`、`state.js`、`GameScene.js`）
- 擊殺地城怪物有機率掉落**技能書**（Boss 必掉 1 本），在背包左鍵閱讀即可習得新技能或將已有技能升級（上限提升至 **Lv.20**，搭配特殊詞條最高可達 **Lv.30**，持續增強威力並縮短冷卻）。
- 可於背包左欄切換「**技能書庫**」（共 3 頁），自由將已習得技能設定至快捷欄 `1~5`：
  - **初始 3 招**：`火球`、`旋風斬`、`治療`
  - **既有進階 4 招**：`連鎖閃電`、`寒冰新星`、`暗影突襲`、`烈焰隕石`
  - **新增 10 招進階技能**：
    - `裂地斬`：前方扇形火焰重斬並強力擊退敵人
    - `寒冰長矛`：高速穿透型冰槍，減速並傷害沿途敵人
    - `劇毒迷霧`：在游標位置生成持續 4.5 秒的毒霧區域造成持續傷害與緩速
    - `聖光護盾`：獲得吸收大量傷害的金色護盾（8 秒）
    - `鮮血狂怒`：7 秒內提升攻擊 +35%、攻速 +25%、吸血 +15%
    - `秘法光球`：緩慢推進並連續電擊周圍敵人，終點引發紫爆
    - `暗影閃現`：瞬移至游標方向並於落點引爆暗影衝擊波
    - `天雷裁決`：連續召喚多道垂直落雷轟擊敵群
    - `劍刃風暴`：召喚 3 把環繞飛劍持續切割周圍敵人與木桶
    - `靈魂收割`：釋放大範圍爆發並將 25% 傷害化為自身生命

### 5. 8 部位裝備、特殊裝備詞條與升級成長（`items.js`、`state.js`）
- **全身 8 個可裝備部位**：`武器`、`頭盔`、`盔甲`、`披風`、`護手`、`鞋子`、`項鍊`、`戒指`。
- 裝備分為**普通（白）**、**魔法（藍）**、**傳奇（金）**與**特殊傳世（橘）**四種品質，掉落時附帶對應色調光柱與隨機 **0~3 個符文插孔**。
- **17 種特殊詞條與 16 件命名特殊裝備**：除冷卻縮減、單／全技能等級 +X、吸血、反傷、移速／攻速、爆擊、電弧／冰霜觸發技外，還包含**掉寶率加成（`magicFind`）**；餘燼神鑄（25% 機率）、Boss 與寶箱均會產出專屬命名特殊神裝。
- 擊殺怪物累積經驗升級，每次升級回滿血魔並獲得 **5 點**屬性點，可自由分配至**力量**（攻擊）、**體質**（生命／防禦）、**智力**（法力／技能傷害）。

### 6. 4 件套裝系統、頭目定向掉落與鐵匠保底（`sets.js`、`items.js`、`GameScene.js`）
- **定位區隔與混搭空間**：符文負責泛用增益光環，**套裝（翠綠品質與翠綠光柱）**主打流派機制質變；全身 8 部位中每套僅佔 **4 件**，可於後期自由搭配「`4+4` 雙套裝」或搭配散裝神鑄武器。
- **頭目定向掉落**：擊敗各層守關 Boss 會獲得 **+1 套裝精華**，並高機率（基礎 65%，受掉寶率加成最高 92%）定向掉落該 Boss 對應套裝（優先產出尚未收集的部位）。
- **鐵匠套裝保底機制**：於餘燼村找鐵匠布朗拆解多餘套裝必得 **+1 套裝精華**，支援：
  - **轉換同套部位**：花費金幣 + 1 套裝精華，將多餘部位轉換為同套其他部位（優先缺漏部位），並**保留強化等級、插孔與已鑲嵌符文**。
  - **套裝定向保底**：切換鍛造面板右下角「**套裝定向保底**」，消耗金幣 + 餘燼石 + 2 套裝精華，直接指定套裝與指定部位鍛造。
- **Tooltip 套裝連動**：懸停或選取套裝物品時，下方即時顯示 4 個部位的穿戴狀態（已穿／未穿）與 2/4 件效果啟動狀態。

| 套裝名稱 | 掉落頭目 | 包含部位 | 2 件套啟動效果 | 4 件套核心質變 |
| :--- | :--- | :--- | :--- | :--- |
| **骸骨戰神** | 骸骨暴君 | 頭盔、盔甲、護手、鞋子 | 攻擊 +18%、減傷 +8%、旋風斬與裂地斬 +2 | 旋風斬結束釋放「骸骨震地波」（155px 220% 傷害並強力擊退） |
| **血月獵影** | 血月主教 | 武器、披風、項鍊、戒指 | 翻滾冷卻 -30%、爆傷 +45%、攻速 +15% | 翻滾／突襲／閃現後獲得 4 秒「影殺印記」，下次攻擊必爆擊且額外 +50% 傷 |
| **霜炎秘法** | 霜魂領主 | 頭盔、披風、護手、項鍊 | 技傷 +25%、冷卻 -12%、耗魔 -15% | 火球爆炸分裂 3 顆追蹤小火球；寒冰技能對緩速目標傷害 +40% |
| **深淵疫主** | 深淵領主 | 盔甲、鞋子、項鍊、戒指 | 全技能 +1、反傷 +50%、擊殺回血 +15/回魔 +10 | 毒霧／靈魂收割擊殺時引發瘟疫毒爆與擴散新毒霧；擊殺縮短全技能冷卻 1 秒 |

### 7. 符文插孔與 8 大組合符文光環（`runes.js`、`UIScene.js`、`GameScene.js`）
- 擊殺怪物、開啟寶箱或打破木桶／陶罐可機率性拾取 **8 種符文石**（一般怪掉落率調降為稀有掉落，可透過**掉寶率**詞條或光環提升機率）：`血符`、`棘符`、`風符`、`焰符`、`霜符`、`奧符`、`噬符`、`聖符`。
- **鐵匠打孔與重鑄**：在餘燼村找鐵匠布朗可使用金幣與餘燼石替裝備**打孔**（最高 3 孔），且**重鑄屬性會保留原有插孔與已鑲嵌符文**。
- 按 `B` 切換左欄「**符文鑲嵌**」分頁即可進行鑲嵌／取出。同一件裝備內湊滿指定符文組合將啟動對應**符文光環**：

| 符文光環名稱 | 所需符文組合 | 光環核心效果 |
| :--- | :--- | :--- |
| **嗜血光環** | 血符 + 焰符 | 吸血 +10%、擊殺回血 +15 |
| **荊棘光環** | 棘符 + 霜符 | 反傷 +65%、防禦 +12 |
| **疾風光環** | 風符 + 噬符 | 移速 +22%、攻速 +20%、翻滾冷卻 -20% |
| **烈焰光環** | 焰符 + 奧符 | 定期灼燒周圍敵人、技能冷卻 -8% |
| **寒霜光環** | 霜符 + 風符 | 持續緩速並凍傷周圍敵人、減傷 +10% |
| **秘法湧動光環** | 奧符 + 風符 + 聖符 | 全技能等級 +1、冷卻 -18%、耗魔 -15%、回魔 +150% |
| **不滅血棘光環** | 血符 + 棘符 + 聖符 | 吸血 +12%、反傷 +80%、減傷 +15%、每秒回血 2% |
| **尋寶光環** | 噬符 + 聖符 | 掉寶率 +45%、金幣掉落 +40%、爆擊率 +5% |

### 8. 地城互動物件、陷阱與祝福祭壇（`GameScene.js`、`textures.js`）
- **寶箱**：探索地城時會遭遇上鎖寶箱（已探索區域的小地圖上以黃色方點標記），靠近按 `F` 或左鍵點擊開啟，噴出金幣、裝備、符文、餘燼石與技能書。
- **可破壞木桶與陶罐**：可點擊擊碎，或使用火球、旋風斬等範圍技能一次震碎，有機率掉落金幣、符文石與**生命／法力靈球**（踩過立即回復）。
- **地城陷阱**：房間內配置定期伸縮的**地刺**與雙刃**擺斧陷阱**，同時會傷害玩家與踩入的怪物。
- **祝福祭壇**：已探索小地圖上以青色方點標記，按 `F` 或點擊互動可隨機觸發治療、**狂戰祝福**（提升攻擊與移動速度）、**奧術祝福**（大幅加快回魔並縮短技能冷卻）或**貪婪祝福**（大量金幣與碎片），左上 HUD 會即時顯示剩餘秒數。
- **地城毒蛛、蛛網與環境道具**：毒蛛可遠距發射蛛網彈製造減速蛛網（火球／烈焰隕石可將蛛網燒毀）；各房配置動態火光火盆、牆面鐵鍊與墓碑，餘燼村亦有武器架、戰旗與枯樹裝飾。

### 9. 3DGarden 自訂素材替換指南（`assetOverrides.js`、`manifest.json`）
遊戲預設以純程式化紋理執行，不依賴外部資產即可零缺檔啟動；同時預留了素材覆寫接口，可將從 [3DGarden Medieval Dungeon](https://www.3dgarden.app/browse) 挑選並渲染／匯出的 2D 俯視 PNG 精靈圖直接替換進遊戲中：
1. 將準備好的透明背景 PNG 放至 `public/assets/overrides/`（建議尺寸 32×32 或 64×64）。
2. 在 `public/assets/overrides/manifest.json` 的 `"overrides"` 陣列加入 `{ "key": "<貼圖Key>", "path": "assets/overrides/<檔名>.png" }`。
3. 重啟或重新整理後，`BootScene` 會優先載入清單內的圖檔，並跳過同 Key 的程式化繪製流程。

### 10. 進度儲存與 GitHub Pages 線上分享（`save.js`、`.github/workflows/deploy.yml`）
- **自動與手動存檔**：點擊右下「**存檔**」鈕、於餘燼村與地城層數間傳送、強化鍛造、穿卸裝備、鑲嵌符文、升級或擊敗 Boss 皆會自動將完整角色進度儲存至瀏覽器 `localStorage`；重開網頁後主選單將顯示「**繼續遊戲**」與進度摘要。
- **死亡懲罰緩和**：角色倒下時可選擇「**回村復活**」保留身上裝備與成長，或「**重新開始**」開啟新冒險。
- **推上 GitHub 倉庫給其他人玩（GitHub Pages）**：
  專案已設定 `vite.config.js` 的 `base: './'` 與自動部署工作流程 `.github/workflows/deploy.yml`：
  1. 在本機建立 Git 並推送至 GitHub（分支名稱 `main`）：
     ```bash
     git init
     git add .
     git commit -m "Release Ember Dungeon"
     git branch -M main
     git remote add origin https://github.com/<你的帳號>/<倉庫名稱>.git
     git push -u origin main
     ```
  2. 前往 GitHub 倉庫的 **Settings → Pages → Build and deployment → Source**，選擇 **GitHub Actions**。
  3. 推送後等待 Actions 完成建置，即可直接分享 `https://<你的帳號>.github.io/<倉庫名稱>/` 讓所有人用瀏覽器遊玩。
